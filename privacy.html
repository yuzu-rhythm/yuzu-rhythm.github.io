プライバシーポリシー

Pi Mailbot は作者本人だけが使う個人用ツールです。

  • Google アカウントへのアクセスは、作者本人の Gmail アカウントのメールを一覧表示・分類・アーカイブ・ゴミ箱へ移動するためだけに使います。
  • 取得したメールの情報は作者本人の Raspberry Pi の中だけで扱い、第三者に提供・販売しません。広告や AI の学習には使いません。
  • メール本文は画面に表示するときに一時的に読み込むだけで、保存しません。
  • Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • アクセスは Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

Privacy Policy

Pi Mailbot is used only by its author. Google account access is used solely to list, label, archive and trash the author's own Gmail messages on the author's Raspberry Pi. Data is not shared, sold, used for advertising or for AI training, and message bodies are not stored. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
